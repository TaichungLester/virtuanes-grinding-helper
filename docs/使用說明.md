# VirtuaNES 練功助手

支援目前使用的《吞食天地1中文版》及 2X／3X 視窗模式，範圍自動換算，不用框選。F7 保留給模擬器原有設定。

1. 開啟「VirtuaNES練功助手.exe」，在助手視窗按 Enter 或點「開始」，10 秒內切回遊戲。
2. 原野上先按 V 檢查兵力；支援可見的五至七人名單。有軍師時排除軍師，取其餘名單的前五位；無軍師時取前五位。後備武將不列入出戰上限。每次檢查都重新取得上限，包含升級後的變化。
3. 自動左右移動遇敵，按右、Z（A）發動總攻。戰鬥中不讀取兵力，持續打到結束。
4. 勝利、經驗值、升級等戰後對話會逐頁按 Z，直到原野畫面，再按 V 檢查。任一出戰武將嚴格低於設定比例時停止並提醒；預設 50%。
5. 遊戲中按 Esc 停止，或點助手「停止」。切離遊戲也會停止送出按鍵。

停止助手只會停止按鍵，不會按 P，也不會呼叫模擬器的暫停功能。若之前已暫停，請自行用模擬器的 P 或「編輯 → 暫停」恢復。

「只檢查畫面／兵力」是唯讀檢查：先在遊戲按 V 顯示兵力，再按檢查，3 秒內切回遊戲。數字至少兩種影像處理結果一致且信心達 90% 才接受；若有軍師卻無法對應可見列，會停止。

可從原野、V 兵力頁或戰鬥中開始。戰鬥中開始會先打完這場，再讀取目前隊伍。戰鬥中不因兵力變動或讀值不同而停止；低兵力檢查延至戰後。

保持遊戲完整顯示，不要最小化或被其他視窗遮住。不會補血、逃跑、改寫記憶體、讀檔或覆蓋存檔。練功區域由你選擇。

保留程式旁的「_internal」與「VirtuaNES預設」資料夾。
