# VirtuaNES《吞食天地 1》中文版練功助手使用說明

本程式針對 **FC／NES《吞食天地 1》中文版 ROM** 製作，使用 VirtuaNES 運行遊戲，再由助手辨識畫面、送出鍵盤操作。下載包只提供助手，不含 ROM、模擬器或存檔。

## 一、適用 ROM 與執行環境

| 項目 | 設定與適用範圍 |
| --- | --- |
| 作業系統 | 本次已使用 **Windows 11 64 位元（x64）**；其他 Windows 版本與其他作業系統尚未完整驗證 |
| 模擬器 | **VirtuaNES 中文介面版（VirtuaNES_cht）**，沿用系統預設按鍵；本次執行檔的檔案版本資訊為 `0.92`，此數值為檔案中繼資料 |
| ROM | **FC／NES《吞食天地 1》中文版 `.nes` ROM**，本次遊戲名稱為《吞食天地1中文版》；武將、兵力頁與戰鬥對話須呈現相同中文文字及版面 |
| 遊戲畫面 | **視窗模式，2X 或 3X**；範圍自動換算，不需要框選。遊戲須完整顯示並保持在前景，不要最小化或被其他視窗遮住 |
| Python | 直接使用 Windows 執行版不必安裝 Python。從原始碼執行時，本次使用 Python 3.12.14 64 位元，依專案 `requirements.txt` 安裝套件 |

本助手不適用《吞食天地 2》或瀏覽器遊戲。日文、英文 ROM、其他漢化補丁、改版、不同字體、濾鏡、其他模擬器與全螢幕模式尚未驗證。目前未記錄測試 ROM 的漢化補丁版本與校驗碼，因此不能保證所有同名「中文版」都相容。

按鍵沿用 VirtuaNES 系統預設，無須另外更改。

## 二、安裝與首次檢查

1. 從 GitHub Releases 下載 Windows ZIP，**完整解壓縮**後執行 `VirtuaNES練功助手.exe`，不要直接在壓縮檔內執行。
2. 保留程式旁的 `_internal`、`VirtuaNES預設` 資料夾，兩者都必須與執行檔放在同一層。
3. 在 VirtuaNES 載入中文版 ROM，調成 2X 或 3X 視窗模式。若遊戲已暫停，先用模擬器的 P 或「編輯 → 暫停」恢復。
4. 在原野手動按 V，確認能顯示中文兵力頁，再試 X 能回到原野。
5. 在助手按「只檢查畫面／兵力」，**3 秒內切回遊戲兵力頁**。這項檢查不會送出遊戲按鍵。
6. 確認助手顯示的第 1～5 位目前兵力與上限正確，再開始練功。換 ROM、倍率或畫面濾鏡後，請重新檢查。

## 三、開始與停止

1. 在適合練功的原野待命，開啟助手後，在**助手視窗按 Enter 或點「開始」**。
2. **10 秒內切回 VirtuaNES 遊戲視窗**，保持遊戲未暫停且完整可見。
3. 助手先按 V 檢查兵力，再左右往返遇敵；戰鬥選單按「右 → Z（A）」發動總攻。
4. **戰鬥中不讀取兵力，會持續打到結束**；勝利、經驗值、升級等戰後訊息會逐頁按 Z，直到回到原野。
5. 回原野後再按 V 檢查。任一出戰武將兵力**嚴格低於**門檻時停止並提醒；預設 **50%**，剛好 50% 不會因門檻停止。
6. 遊戲中按 **Esc**，或點助手「停止」可手動停止。切離遊戲視窗也會停止送出按鍵。

停止助手只會停止按鍵，**不會按 P 或暫停模擬器**。戰鬥開始後不會因兵力變動、兩次讀值不同或低於門檻而中途停止；低兵力檢查在戰後進行。

可從原野、V 兵力頁或戰鬥中開始。從戰鬥開始時，會先打完這一場，再回原野讀取目前隊伍。

## 四、隊伍、軍師與辨識

- 支援兵力頁可見的 **五至七人名單**。
- 有軍師時，依圖像比對排除軍師，取其餘名單的**前五位**；軍師欄空白時取名單前五位。
- 後備武將不列入出戰上限，不綁定武將姓名；更換順序、軍師或升級後，每次兵力頁檢查都重新取得上限。
- 兵力數字需至少兩種影像處理結果一致，且辨識信心達 90% 才接受；軍師無法對應可見名單或兵力頁數字無法可靠辨識時停止。

若無法辨識，先確認使用的是相同中文版 ROM、遊戲未暫停、倍率為 2X／3X、畫面完整且未被遮住，再使用唯讀檢查。不要假設其他漢化或模擬器能直接沿用。

助手不會補血、自動逃跑、修改記憶體、讀檔或覆蓋存檔；練功地區由使用者選擇。
